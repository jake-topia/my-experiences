# my-experiences

This project was bootstrapped with Topia Tools.

## Available Scripts

In the project directory, you can run:

### `npm run dev`
Starts the development server with Topia integration and hot reload.

### `npm run build`
Builds the app for production to the `dist` folder.

### `npm run topia:import`
Import a Topia project into your local workspace.

### `npm run topia:sync`
Sync your local changes back to Topia.

### `npm run topia:init`
Initialize or reconfigure Topia API access.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Initialize Topia configuration:
   ```bash
   npm run topia:init
   ```

3. Import a Topia project:
   ```bash
   npm run topia:import
   ```

4. Start development:
   ```bash
   npm run dev
   ```

5. Edit your scripts in the `projects/` directory
6. Changes will be automatically synced to Topia
